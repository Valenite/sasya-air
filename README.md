## 🚀 Live Deployment on Vercel
Deployable on Vercel as a zero-config production web application.
- Framework: Three.js 3D WebGL, Tailwind CSS, Lucide Icons, Vanilla ES6.
- Interactive Features: Real-time 3D Chalice rotation, multi-mode lighting, interactive Saptānga 7-pillar breakdown, complete e-commerce cart drawer, and consumer cost-savings calculator.
